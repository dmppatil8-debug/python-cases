
# Log File Analyzer

A Python project that generates and analyzes large server log files using generators and streaming processing.

## Project Overview

This project generates a server log containing 200,000 records and then analyzes the data without loading the entire file into memory.

The project demonstrates:

- Generators
- yield
- Regular expressions
- Counter
- defaultdict
- File handling
- Streaming data processing
- Large file processing
- tracemalloc
